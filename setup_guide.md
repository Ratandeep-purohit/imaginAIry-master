# imaginAIry — Complete Setup Guide

> **Goal:** Follow this guide on a completely new Windows laptop, even if you have never worked with Python, Git, or AI before.
>
> **Recommended platform:** Windows 10/11 + NVIDIA GPU. CPU mode is possible but can be much slower.

---

## 1. What is imaginAIry?

**imaginAIry** is a Python-based AI image-generation project. You write a text prompt such as:

```text
a cinematic photograph of a futuristic city at night
```

and the program generates an image.

Main commands:

- `imagine` → generate images
- `aimg` → additional commands such as server, video, and upscaling

The repository also contains an HTTP API and web interface.

---

# 2. Before you start

Recommended:

| Component | Recommended |
|---|---|
| OS | Windows 10/11 64-bit |
| RAM | 16 GB+ |
| Free disk space | 30–50 GB+ |
| GPU | NVIDIA GPU strongly recommended |
| GPU VRAM | 8 GB+ recommended |
| Python | 3.10 or 3.11 |
| Internet | Required during initial setup/model downloads |

AI models can occupy several GB. Keep plenty of free storage.

**Laptop tip:** For AI generation, keep the charger connected and keep the ventilation clear.

# 3. Check for an NVIDIA GPU

Press **Windows + R**, type `cmd`, and press Enter.

Run:

```bat
nvidia-smi
```

If an NVIDIA GPU table appears, great.

If `nvidia-smi` is not recognized, either the NVIDIA driver is not installed or the laptop does not have an NVIDIA GPU.

You can continue without NVIDIA, but CPU generation can be much slower.

# 11. Install PyTorch

PyTorch is the main deep-learning framework used by imaginAIry.

## NVIDIA GPU users

Use the official PyTorch installation selector:

https://pytorch.org/get-started/locally/

Select:

- OS: **Windows**
- Package: **Pip**
- Language: **Python**
- Compute Platform: the CUDA option recommended for your NVIDIA driver

Copy the command generated by the PyTorch website and run it inside the active `.venv`.

**Do not copy a random CUDA command from an old tutorial.** The correct PyTorch/CUDA command can change over time.

## CPU-only users

If you have no NVIDIA GPU, use the CPU installation command provided by the official PyTorch selector.

---

# 12. Check PyTorch

Run:

```bat
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA available:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

For an NVIDIA setup, you want:

```text
CUDA available: True
GPU: NVIDIA GeForce ...
```

If it says `GPU: CPU`, see the troubleshooting section below.

# 16. Generate a normal image

Now try:

```bat

```

The repository is configured for a faster default diffusion setup, so 20 steps is a good starting point.

---

# 17. Why is the first image slower?

The first run can include:

1. Starting Python
2. Starting PyTorch
3. Loading model files
4. Downloading model files if they are not cached
5. Moving models into GPU memory
6. Initializing text/image encoders
7. Actual image generation

Later generations can be much faster because expensive model state can be reused.

**Test 2–3 generations before judging performance.**

---

# 18. Fast generation

For a quick test:

```bat
imagine "a mountain landscape" --size 256 --steps 10
```

For a balanced image:

```bat
imagine "a beautiful mountain landscape at sunset" --size 512 --steps 20
```

For higher detail:

```bat
imagine "a cinematic mountain landscape at sunset, realistic photography, detailed clouds, dramatic lighting" --size 768 --steps 30
```

In general:

```text
smaller image + fewer steps = faster generation
larger image + more steps = slower generation
```

---

# 19. Important command options

### Prompt

```bat
imagine "a golden retriever sitting in a garden"
```

### Steps

```bat
--steps 20
```

More steps mean more computation.

A useful starting point:

- 10–20 → fast
- 20–30 → balanced
- 30+ → slower

### Size

```bat
--size 256
--size 512
--size 768
```

Large images need more GPU memory and computation.

### Seed

```bat
--seed 123
```

A seed helps reproduce comparable results when the model and other settings are unchanged.

# 22. Troubleshooting

## A. `python is not recognized`

Example:

```text
'python' is not recognized as an internal or external command
```

Install Python again and enable:

```text
☑ Add python.exe to PATH
```

Then close and reopen Command Prompt.

Check:

```bat
python --version
```

---

## B. `git is not recognized`

Install Git:

https://git-scm.com/download/win

Then reopen Command Prompt and run:

```bat
git --version
```

---

## C. `imagine is not recognized`

Check that the environment is active:

```text
(.venv)
```

Then run:

```bat
python -m pip install -e .
imagine --help
```

---

## D. PowerShell refuses to activate the environment

For beginners, use **Command Prompt (cmd)** instead.

Run:

```bat
cd /d C:\AI\imaginAIry-master
.venv\Scripts\activate
```

---

## E. CUDA says False

Run:

```bat
nvidia-smi
```

If that fails, check/install the NVIDIA driver.

If `nvidia-smi` works but PyTorch still says CUDA is unavailable, run:

```bat
python -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.is_available())"
```

Then reinstall PyTorch using:

https://pytorch.org/get-started/locally/

Do not randomly mix CUDA/PyTorch packages from different tutorials.

---

## F. CUDA out of memory

If you see:

```text
CUDA out of memory
```

reduce the image size and steps:

```bat
imagine "your prompt" --size 256 --steps 10
```

Then try:

```bat
imagine "your prompt" --size 512 --steps 20
```

Also close games, Blender, video editors, and other GPU-heavy applications.

---

## G. Generation is extremely slow

Check GPU usage:

```bat
python -c "import torch; print('CUDA:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

If it says:

```text
GPU: CPU
```

you are generating on CPU.

For an NVIDIA laptop, fix the PyTorch/CUDA installation before judging image-generation speed.

---

## H. First generation is extremely slow

This can be normal.

The first run may download/load model weights.

After it finishes, generate another image:

```bat
imagine "a blue bird" --size 512 --steps 20
```

Compare the second generation rather than only the first.

---

## I. Installation stopped with an error

Do not immediately delete everything.

First capture the **last 20–30 lines of the error**.

Also run:

```bat
python --version
python -m pip --version
git --version
nvidia-smi
```

These outputs usually make the problem much easier to identify.

---

# 23. Laptop performance tips

For sustained AI generation:

- Keep the charger connected.
- Use Windows **Best performance** mode when available.
- Keep laptop vents clear.
- Avoid running games or other GPU-heavy programs at the same time.
- Make sure enough disk space is available.
- Do not close the terminal while a generation is running.

Gaming laptops may become warm under sustained GPU load. That is expected, but good ventilation matters.

# 27. Do not casually delete model caches

Model/cache directories can contain large AI model files.

Deleting them can force the application to download or prepare models again.

If you need to free disk space, identify the cache first instead of deleting random folders.

# 28. Clean reinstall

If the Python environment itself becomes broken, recreate only the virtual environment first.

From the project directory:

```bat
rmdir /s /q .venv
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip setuptools wheel
```

Then reinstall PyTorch from the official selector:

https://pytorch.org/get-started/locally/

Then:

```bat
python -m pip install -e .
```

Finally test:

```bat
imagine "a small green apple" --size 128 --steps 3 --seed 1
```
